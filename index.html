Integrasi & Hosting Gratis di Vercel

Unduh file index.html yang sudah menyertakan seluruh hasil editan teks, foto, & pengaturan tata letak bingkai terbaru Anda untuk di-online-kan gratis di Vercel.

Export File Siap Deploy (index.html)

Seluruh perubahan teks, jadwal, struktur keluarga, foto almarhum, dan tata letak bingkai akan tertanam permanen di dalam file ini sehingga semua tamu dapat membukanya dari HP mana saja.

Cara Upload / Update ke Vercel (Gratis Tanpa Coding):

1
Download index.html

Klik tombol Download index.html Terbaru di atas, lalu simpan file tersebut di dalam satu folder khusus (misal: folder undangan-tahlilan).

2
Upload ke GitHub / Vercel

Buat akun gratis di vercel.com, hubungkan repository GitHub Anda (atau gunakan Vercel CLI npx vercel --prod) dan klik Deploy.

3
Bagikan Link .vercel.app

Salin domain gratis Anda (contoh: tahlilan-jufri.vercel.app) lalu sebarkan link personal ke WhatsApp para tamu.

Ubah PIN Dashboard Admin

Ganti PIN default (123456) dengan PIN pribadi Anda agar halaman admin tetap aman.

Reset ke Data Default Undangan

Mengembalikan seluruh teks, jadwal, foto, dan daftar keluarga ke pengaturan awal Alm. JUFRI NA'ANE BIN LA NA'ANE.
